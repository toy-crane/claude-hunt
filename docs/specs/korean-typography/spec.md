# 한글 글꼴 개선

## 목적

클로드 헌트의 모든 화면에서 한글이 서비스가 선언한 글꼴로 일관되게 보이게 한다. 지금은 본문·제목·모노 세 글꼴 역할 모두 한글 글리프가 없어 한글이 운영체제 기본 글꼴로 대체되고, 모노 제목 안의 공백이 모노 폭이라 한글 단어 사이가 벌어진다. shadcn 테마(색·모서리·간격 토큰, 컴포넌트 구조)는 그대로 두고 글꼴 역할만 바꾼다.

## 기대 결과

- 한글 제목·본문·라벨이 Mac, Windows, Android, iOS에서 같은 글꼴(Pretendard)로 보인다.
- 한글 제목의 단어 간격이 본문과 같은 비율로 자연스럽다.
- 한글과 영문이 섞인 프로젝트 제목이 한 글꼴로 정리된다.
- 터미널 향을 만드는 요소(프롬프트 줄, 로고, 표 열 머리, 순위 번호, 추천 수)는 그대로 남는다.
- 글꼴 때문에 첫 화면이 눈에 띄게 느려지지 않는다.

## 승인된 범위

### 글꼴 역할

- 글꼴 역할은 두 가지다. 산세리프는 Pretendard, 모노는 Geist Mono다. 제목 전용 글꼴(JetBrains Mono)은 더 이상 싣지 않는다.
- 산세리프 역할: 페이지 제목, 카드·행 제목, 본문과 설명, 버튼·링크 문구, 사람 이름, 클래스 이름, 폼 라벨과 입력값, 안내·오류 문구.
- 모노 역할: 시스템이 만든 문자열에만 쓴다. 명령줄·프롬프트 문자열(`$ claude-hunt ls --sort=votes`, `$ cd /projects`), 로고 `>claude-hunt_`, 표 열 머리(RANK · PREVIEW · NAME · AUTHOR · VOTES), 순위 번호(01, 02 …), 추천 수, 개수 배지(예: 프로젝트 탭의 161).
- 한글이 포함된 텍스트는 어떤 자리에서도 모노 역할을 쓰지 않는다. 지금 모노로 표시되는 다음 자리는 산세리프로 옮긴다.
  - 클래스 칩(`모든 클래스 161`, `LG전자 9기 27`)과 카드의 클래스 표시(`01 · LG전자 4기`의 클래스 부분)
  - 이달의 프로젝트 배지에서 `RANK 01` 뒤의 `이달의 프로젝트`
  - 히어로 메타 줄(`LG전자 8기 · 18일 전`)
  - `프로젝트 자세히 보기`, `프로젝트 보드 →` 같은 링크 문구
  - 작성자 이름(한글·영문 무관)
- 한 요소 안에서 시스템 문자열과 한국어 문구가 함께 있으면(예: `RANK 01 · 이달의 프로젝트`) 시스템 문자열만 모노로 두고 나머지는 산세리프로 둔다. 칩·배지 안의 숫자는 자릿수가 맞는 숫자(tabular)로 표시한다.

### 굵기

- 페이지 제목과 히어로·카드의 큰 제목(홈 `이달의 클로드 헌트`, 보드 `프로젝트 보드`, 상세 제목, 이달의 프로젝트 제목): 600.
- 행 제목, 카드 제목, 소제목, 섹션 제목, 안내 카드 제목: 500.
- 본문·설명: 400. 강조(작성자 이름 등)는 500.
- 다크·라이트 테마에서 같은 굵기를 쓴다. 다크 테마용 굵기 보정은 하지 않는다.
- 모노 역할의 굵기는 지금과 같다.

### 글꼴 제공 방식

- Pretendard와 Geist Mono 모두 서비스가 직접 제공한다. 외부 글꼴 CDN에 의존하지 않는다.
- 한글 글꼴은 화면에 쓰인 글자 범위만 나눠 내려받는다. 전체 파일(약 2MB)을 한 번에 보내지 않는다.
- 글꼴이 도착하기 전에도 한글은 운영체제의 기본 한글 산세리프로 읽히고, 교체될 때 레이아웃이 크게 흔들리지 않는다.

### 적용 화면

- 모든 화면에 적용한다. 홈, 프로젝트 보드(데스크톱·모바일), 프로젝트 상세, 프로젝트 제출·편집, 로그인, 온보딩, 설정, 이용약관·개인정보 처리방침, 오류·빈 상태.

## 수용 기준

- 홈 제목 `이달의 클로드 헌트`가 Pretendard 600으로 렌더링되고, 브라우저가 계산한 글꼴 목록의 첫 글꼴이 Pretendard다.
- 프로젝트 보드 행 제목 `비행기 게임(AI 역습 - AI에서 인류를 지켜주세요!)`의 한글과 영문이 모두 Pretendard 500으로 렌더링된다.
- Mac과 Windows에서 같은 뷰포트로 찍은 홈·보드·상세의 한글 제목 스크린샷이 같은 글꼴 형태다. 운영체제 기본 한글 글꼴로 대체된 곳이 없다.
- 프롬프트 줄, 로고, 표 열 머리, 순위 번호, 추천 수는 Geist Mono로 유지된다.
- 페이지의 텍스트 요소 가운데 한글을 포함하면서 계산된 글꼴이 모노인 요소가 0개다. 홈, 보드(데스크톱·모바일), 상세, 로그인에서 확인한다.
- 로드되는 글꼴 패밀리는 Pretendard와 Geist Mono 둘뿐이다. JetBrains Mono는 요청되지 않는다.
- 캐시를 비운 상태의 첫 로드에서 글꼴 요청 가운데 1MB 이상인 파일이 없다. 홈, 프로젝트 보드, 프로젝트 상세, 로그인, 이용약관, 개인정보 처리방침 각각을 측정하며, 홈의 글꼴 전송량 합계는 600KB 이하다. 다른 페이지의 합계도 기록해 홈 한도를 넘는 페이지를 남긴다.
- 글꼴 요청이 서비스 도메인 밖으로 나가지 않는다.
- 다크·라이트 테마에서 제목 굵기가 같다.
- 홈·보드·상세의 누적 레이아웃 이동(CLS)이 지금보다 나빠지지 않는다.
- 기존 단위 테스트와 e2e 테스트가 통과한다.

## 제약과 근거

- Pretendard를 고른 이유: Inter를 바탕으로 만든 한글 글꼴이라 라틴 본문의 인상이 거의 바뀌지 않고, 프로젝트 OG 이미지가 이미 Pretendard를 쓰고 있어 서비스 안팎이 같은 글꼴이 된다. SIL OFL 라이선스다.
- 제목을 산세리프로 두는 이유: 지금의 모노 글꼴(JetBrains Mono, Geist Mono)에는 한글 글리프가 없고, 한글을 가진 모노(D2Coding)는 굵기가 400·700 둘뿐이라 제목 위계가 약해진다. 운영 화면에 세 갈래(혼합 쌍, 산세리프 제목, 한글 모노)를 실제로 입혀 비교한 뒤 확정했다.
- 굵기 600/500인 이유: shadcn이 제목과 카드 제목에 쓰는 기본 굵기(semibold)와 맞고, 프로토타입에서 700은 과했다.
- 한글 라벨을 산세리프로 옮기는 이유: 모노 공백이 한글 단어 사이를 벌리고, 글리프만 대체하면 한 줄 안에서 두 글꼴이 섞인다. 터미널 향은 시스템이 만든 문자열에 두면 충분하다.
- 나눠 받는 이유: 한글 글꼴 전체는 약 2MB로 프로젝트 썸네일보다 무겁다. PRODUCT.md의 "프로젝트와 동료의 작업이 장식보다 먼저 보이게"에 따라 글꼴이 첫 화면을 늦춰서는 안 된다.
- PRODUCT.md에서 가져온 제약: 서비스와 운영 문구는 한국어가 기준이다.
- 비교 근거: 글꼴 갈래 비교(https://claude.ai/code/artifact/740ad1cd-c7d0-4974-9d04-20486cd347cf), 굵기·테마 토글 프로토타입(https://claude.ai/code/artifact/31a53ca4-963b-4108-9ebf-ce33240595e1).

## 범위 밖

- 색·모서리·간격 토큰, shadcn 프리셋(radix-vega), 컴포넌트 구조와 레이아웃. 사용자가 shadcn 테마를 유지하기로 했다.
- 터미널 향 구조 문법 이식(섹션 이야기표, 그림 프레임, 단축키 내비 등)과 밝은·어두운 색 세계 결정. 레퍼런스 보드에서 나온 별도 작업이다.
- 모노 글꼴 교체. Geist Mono를 유지한다.
- OG 이미지 글꼴. 이미 Pretendard다.
- 글꼴 크기 체계. 지금 크기를 유지한다.

## 가정

- 작성자 이름은 영문이라도 산세리프로 둔다. 사람 이름은 시스템 문자열이 아니다.
- 모노 역할 목록에 없는 숫자만의 표시(예: 댓글 수)는 지금 상태를 유지한다.
- 한자·특수 기호처럼 Pretendard에 없는 글자는 운영체제 글꼴로 대체돼도 된다.
- 글꼴 전송량 한도 600KB는 홈 기준이며, 구현 때 실측으로 확인한다.

## 보류 사항

- OG 이미지 제목 굵기(500)를 화면 제목 굵기(600)와 맞출지.
- 서비스 밖 표면(이메일 등)의 글꼴.

## 남은 위험

- Windows·Android의 실제 렌더링은 구현 후 확인이 필요하다. 이번 검증은 macOS Chrome에서만 했다.
- 한글이 많은 페이지(이용약관, 개인정보 처리방침)는 나눠 받아도 600KB를 넘을 수 있다. 넘으면 해당 페이지의 한도를 따로 정한다.
- 사용자가 올린 제목에 이모지·한자가 섞이면 한 줄에 여러 글꼴이 나타난다.
