# 이메일 마케팅 수신 동의

## 목적

Claude Hunt 회원이 클로드 활용 뉴스레터, 신규 강의와 이벤트 소식을 이메일로 받을지 직접 선택하고 언제든지 설정에서 변경할 수 있게 한다. 서비스 이용에 필요한 동의와 마케팅 동의를 분리해 온보딩 마찰을 늘리지 않으면서, 향후 이메일 발송에 사용할 수 있는 명시적인 동의와 철회 기록을 남긴다.

## 기대 결과

- 신규 회원은 프로필 설정 과정에서 이메일 소식 수신 여부를 선택할 수 있다.
- 마케팅 동의를 하지 않아도 온보딩을 완료하고 Claude Hunt의 모든 기존 기능을 이용할 수 있다.
- 기존 회원은 프로젝트 탐색을 방해하지 않는 일회성 안내를 통해 설정의 수신 관리로 이동할 수 있다.
- 회원은 설정에서 현재 수신 상태를 확인하고 즉시 동의하거나 철회할 수 있다.
- 향후 발송 대상은 현재 동의 상태가 켜져 있는 회원으로만 제한할 수 있다.

## 승인된 범위

### 제공하는 소식

- 사용자에게는 개별 캠페인을 나열하기보다 `클로드 소식`이라는 하나의 이메일 소식 범주로 설명한다.
- 클로드의 신규 기능과 활용 콘텐츠를 담은 뉴스레터, 신규 강의 및 이벤트 안내를 포함한다.
- 사용자 문구는 받을 가치를 먼저 설명하고, 법적 동의 명칭과 필수 고지는 별도의 상세 영역에서 제공한다.

### 신규 회원 온보딩

- 표시 이름과 클래스 입력 다음, 계속하기 버튼 전에 선택 동의 항목을 둔다.
- 동의 항목은 처음부터 선택하지 않은 상태다.
- 표시 문구는 다음과 같다.
  - 제목: `마케팅 정보 수신에 동의합니다. (선택)`
  - 설명: `클로드를 더 잘 활용하는 데 도움이 되는 뉴스레터와 새로운 강의·이벤트 소식을 이메일로 보내드려요.`
  - 상세 진입점: `자세히 보기`
- 선택 여부와 관계없이 프로필 설정을 완료할 수 있다.
- 동의하지 않고 완료한 회원에게 마케팅 이메일을 보내지 않는다.

### 기존 회원 안내

- 기능 도입 전에 가입하여 수신 여부를 결정한 기록이 없는 로그인 회원에게 프로젝트 보드에서 일회성 안내를 보여준다.
- 안내는 프로젝트 탐색을 가리지 않는 하단 카드이며 다음 문구를 사용한다.
  - 제목: `클로드 소식도 받아보세요`
  - 설명: `클로드를 더 잘 활용하는 데 도움이 되는 뉴스레터와 새로운 강의·이벤트 소식을 이메일로 보내드려요.`
  - 행동: `나중에`, `설정에서 선택`
- `나중에`를 선택하면 안내만 닫히며 마케팅 동의로 처리하지 않는다. 이후 같은 안내를 반복해서 보여주지 않는다.
- `설정에서 선택`을 선택하면 설정의 이메일 소식 영역으로 이동한다.
- 온보딩에서 수신 여부를 이미 결정했거나 설정에서 동의 또는 철회한 회원에게는 이 안내를 보여주지 않는다.

### 설정의 수신 관리

- 프로필 정보 다음에 독립된 이메일 소식 영역을 둔다.
- 다음 문구를 사용한다.
  - 섹션: `이메일 소식`
  - 제목: `클로드 소식 받기`
  - 설명: `클로드를 더 잘 활용하는 데 도움이 되는 뉴스레터와 새로운 강의·이벤트 소식을 보내드려요.`
  - 요약: `이메일 · 동의 철회 또는 회원 탈퇴 시까지`
  - 상세 진입점: `마케팅 정보 수신 동의`
- 하나의 스위치가 저장된 현재 동의 상태를 반영한다.
- 스위치를 켜면 동의가 기록되고 이후 발송 대상에 포함될 수 있다.
- 스위치를 끄면 동의가 즉시 철회되고 이후 마케팅 이메일 발송 대상에서 제외된다.
- 설정의 동의 상태 변경은 프로필, 프로젝트, 추천 등 기존 서비스 이용에 영향을 주지 않는다.

### 상세 동의 내용

- 온보딩과 설정에서 같은 동의 내용을 제공한다.
- 항목과 문구는 다음과 같다.
  - 이용 목적: `클로드 신규 기능 및 활용 콘텐츠, 강의·이벤트 안내`
  - 수집·이용 항목: `이메일 주소`
  - 보유 기간: `동의 철회 또는 회원 탈퇴 시까지`
  - 동의 거부: `동의하지 않아도 Claude Hunt를 이용할 수 있습니다.`
  - 철회 방법: `설정 또는 이메일의 수신거부 링크`
- 상세 내용은 접어서 둘 수 있지만 회원이 동의하기 전에 쉽게 열어 확인할 수 있어야 한다.
- 마케팅 이용 목적과 보유 기간은 동의 화면에서 쉽게 알아볼 수 있게 표시한다.

### 동의 기록

- 회원별 현재 동의 상태와 마지막 동의 또는 철회 시점을 구분해 기록한다.
- 어떤 동의 문구에 동의했는지 확인할 수 있도록 동의 내용의 버전을 기록한다.
- 기존 회원을 자동으로 동의 상태로 전환하지 않는다.
- 계정 탈퇴 시 현재 계정 삭제 원칙에 따라 회원 소유의 동의 기록도 함께 제거한다.

## 수용 기준

- 신규 회원이 선택 항목을 누르지 않고 계속하기를 선택하면 온보딩이 정상 완료되고 마케팅 동의 상태는 꺼짐으로 기록된다.
- 신규 회원이 선택 항목을 누르고 계속하기를 선택하면 온보딩이 정상 완료되고 동의 시점과 동의 내용 버전이 기록된다.
- 수신 여부 기록이 없는 기존 로그인 회원에게만 프로젝트 보드 안내가 한 번 표시된다.
- 기존 회원이 `나중에`를 선택하면 안내가 닫히고 다시 표시되지 않으며 동의 상태는 켜지지 않는다.
- 보드 안내의 `설정에서 선택`을 누르면 이메일 소식 영역을 확인할 수 있는 설정 화면으로 이동한다.
- 설정 스위치는 새로고침하거나 다시 로그인해도 저장된 현재 상태와 일치한다.
- 설정에서 스위치를 켜면 동의 기록이 갱신되고, 끄면 철회 시점이 기록되며 발송 대상에서 즉시 제외된다.
- 온보딩과 설정에서 이용 목적, 이메일 주소, 보유 기간, 동의 거부와 철회 방법을 확인할 수 있다.
- 공개 프로젝트 보드를 보는 비로그인 방문자에게는 동의 안내를 표시하지 않는다.
- 동의하지 않은 회원과 철회한 회원에게는 마케팅 이메일을 발송할 수 없다.
- 개인정보 처리방침은 실제 발송 전까지 같은 이용 목적, 항목과 보유 기간을 반영한다.
- 프로필 설정, 프로젝트 탐색 및 설정의 기존 기능은 동의 여부와 무관하게 동일하게 동작한다.

## 제약과 근거

- 이메일만 수신 채널로 제공한다. 문자, 카카오톡과 앱 푸시는 이번 범위에 포함하지 않는다.
- 서비스 이용에 필수인 프로필 설정과 선택적인 마케팅 동의를 결합하지 않는다.
- 법적 명칭을 설정의 대표 제목으로 사용하지 않고, `클로드 소식 받기` 아래에 `마케팅 정보 수신 동의`로 분리한다.
- `혜택 알림`, `정보 제공`처럼 범위를 알기 어려운 표현은 사용하지 않는다. 제공 범위는 클로드 활용 콘텐츠, 강의와 이벤트로 제한해 설명한다.
- 마케팅 동의는 Claude Hunt의 프로젝트 발견과 참여라는 핵심 경험보다 앞세우지 않는다.

## 범위 밖

- 뉴스레터 작성, 예약, 발송 또는 캠페인 관리 화면
- 이메일 발송 서비스 선정과 연동
- 캠페인별 구독, 관심 주제 선택 또는 개인화
- 문자, 카카오톡, 앱 푸시 등 추가 수신 채널
- 비회원 이메일 구독 폼
- 기존 서비스 알림이나 필수 안내 메일의 수신 설정

## 가정

- 이메일 주소는 로그인 계정에 이미 존재하며 회원이 이 화면에서 별도로 입력하지 않는다.
- 기존 회원 안내의 닫힘 여부는 동의 상태와 별도로 유지한다.
- 실제 이메일에는 발신자 정보와 간편한 수신거부 방법을 제공한다.
- 화면의 시각적 구성, 위치와 상호작용은 함께 저장한 승인 프로토타입을 기준으로 한다.

## 보류 사항

- 실제 이메일 발송을 시작하기 전 수신 동의의 정기 확인 방식과 주기를 별도 발송 운영 범위에서 확정한다.
- 발송 서비스, 발신 도메인, 반송 및 수신거부 처리 방식은 이메일 발송 구현 범위에서 결정한다.

## 남은 위험

- 마케팅 정보와 필수 서비스 안내의 경계가 모호하면 동의하지 않은 회원에게 광고성 정보가 발송될 수 있다. 발송 단계에서 두 대상을 분리해야 한다.
- 동의 문구 또는 제공하는 소식의 범위가 바뀌면 기존 동의로 새 범위를 처리할 수 있는지 재검토하고 필요하면 다시 동의받아야 한다.
- 법령과 규제기관 안내는 바뀔 수 있으므로 실제 발송 전 동의 문구, 개인정보 처리방침과 이메일 표시 사항을 법률 전문가가 최종 확인해야 한다.
